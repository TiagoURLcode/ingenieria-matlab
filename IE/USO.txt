===============================================================================
 IE — MANUAL DE USO
 Caja de herramientas de Instalaciones Electricas.
 Todo es estatico: se llama IE.nombre(...). No hay que crear objetos.
 En la misma carpeta vive TT, transformadores trifasicos, que se usa igual.
===============================================================================

 INSTALACION
   Poner IE.m y TT.m en el path de MATLAB, o trabajar parado en su carpeta.
   Verificar que anda:   >> testIE          (117 controles, todos deben dar true)

 CONVENCIONES QUE VALEN PARA TODO
   - Angulos en GRADOS en la interfaz.
   - Tension y corriente en RMS salvo aviso.
   - Secuencia de fases POSITIVA (ABC): B atrasa 120 a A, C atrasa 240.
   - mu es SIEMPRE permeabilidad RELATIVA (adimensional). El aire es mu = 1.
     mu0 = 4*pi*1e-7 lo pone el codigo, nunca lo pasas vos.
   - dA es crecimiento PROPORCIONAL del area del entrehierro:
       A_gap = A*(1 + dA).   dA = 0.10 significa 10% mas de area.
   - Las funciones que empiezan con "ec" devuelven ECUACIONES SIMBOLICAS sin
     resolver. Las que empiezan con "datos" son el atajo: le pasas un struct
     con lo que sabes y te devuelven todo lo que se pueda despejar.

 INDICE
   1. FASORES Y CIRCUITOS
      pol2rec  parZ  f2l  l2f  d2e  e2d  fasores  divV  divI  potencias
   2. EL MOTOR DE DESPEJE
      despejar
   3. CIRCUITO MAGNETICO
      ecB  datosB  ecSeg  datosSeg  faradayB  reluctSeg  fluxO  fluxE
   4. TRANSFORMADOR MONOFASICO
      ecTrafo  datosTrafo  trafo
      ecPerdidas  datosPerdidas  perdidas  ecPerAprox
   5. TRANSFORMADORES TRIFASICOS  (clase TT)
      TT.YY  TT.DD  TT.YD  TT.DY  TT.mono
   6. RECETAS
   7. LIMITES CONOCIDOS

 >> Z = IE.pol2rec([8; 12], [-30; 45])       % varios de una
 >> Z = [10+5j; IE.pol2rec([8; 12], [-30; 45])]   % mezclado con rectangulares

 OJO: devuelve columna aunque le pases fila.

-------------------------------------------------------------------------------
 Zp = IE.parZ(Z)
-------------------------------------------------------------------------------
 Equivalente de impedancias EN PARALELO. Acepta fila o columna, real o
 compleja, cualquier cantidad.

 >> IE.parZ([10 10])            % ans = 5
 >> IE.parZ([10; 20; 30])       % ans = 5.4545
 >> IE.parZ([10; 1j*10])        % ans = 5 + 5i

 Antirresonancia (L y C puros iguales) da Inf. Es correcto, no es un bug.

-------------------------------------------------------------------------------
 E_L = IE.f2l(E_F)        FASE  -> LINEA   (multiplica por sqrt(3))
 E_F = IE.l2f(E_L)        LINEA -> FASE    (divide  por sqrt(3))
-------------------------------------------------------------------------------
 Solo MODULOS. El desfase de 30 grados no lo aplican: para eso esta fasores,
 o directamente TT si es un transformador.

 >> IE.f2l(220)     % ans = 381.05
 >> IE.l2f(380)     % ans = 219.39

 Valido en sistemas equilibrados. Se lee "de fase a linea" y "de linea a
 fase": el primer caracter es lo que ENTRA.

-------------------------------------------------------------------------------
 Zy = IE.d2e(Zd)          DELTA -> ESTRELLA   (transformacion de Kennelly)
 Zd = IE.e2d(Zy)          ESTRELLA -> DELTA
-------------------------------------------------------------------------------
 OJO: esto es para IMPEDANCIAS, no para tensiones. Para tensiones el par es
 f2l / l2f. Confundirlos es el error clasico: el sqrt(3) es de tensiones,
 el 3 es de impedancias.

 EQUILIBRADO (entra un ESCALAR, sale un ESCALAR):
     Z_Y = Z_D/3          Z_D = 3*Z_Y
 Una carga en triangulo consume 3 veces la potencia que la MISMA impedancia
 en estrella: por eso Z_Y = Z_D/3.

 >> IE.d2e(30)      % ans = 10
 >> IE.e2d(10)      % ans = 30

 GENERAL (entra un VECTOR de 3, sale un VECTOR de 3). Orden FIJO:
     D: [Zab; Zbc; Zca]        Y: [Za; Zb; Zc]
   (Za es el brazo que cuelga del nodo A hacia el neutro.)

     D->Y : cada brazo Y = producto de las DOS ramas D que tocan ese nodo,
            sobre la suma de las tres.
     Y->D : con P = Za*Zb + Zb*Zc + Zc*Za, cada rama D = P sobre el brazo Y
            OPUESTO:  Zab = P/Zc,  Zbc = P/Za,  Zca = P/Zb

 >> IE.d2e([30; 60; 90])          % desequilibrado, sale [15; 10; 30]
 >> IE.d2e(IE.pol2rec([30;30;30],[60;60;60]))     % acepta complejos

 Errores: IE:deltaDegenerado (Zab+Zbc+Zca = 0), IE:d2eTamano (ni 1 ni 3).

 M = IE.fasores(E_AN)
 M = IE.fasores(E_AN, ang0)
-------------------------------------------------------------------------------
 Tabla completa de un trifasico equilibrado, secuencia POSITIVA (ABC).
   E_AN : magnitud RMS de la fase A. ESCALAR.
   ang0 : angulo de E_AN en grados. Opcional, 0 por defecto.

   M : matriz 6x4
        columnas ->  [ RMS   angulo(grados)   Pico   Pico-a-pico ]
        filas    ->  1 AN   2 BN   3 CN   4 AB   5 BC   6 CA

 >> M = IE.fasores(220)
      220.00     0.00    311.13    622.25     <- AN
      220.00   240.00    311.13    622.25     <- BN
      220.00   120.00    311.13    622.25     <- CN
      381.05    30.00    538.89   1077.78     <- AB
      381.05   270.00    538.89   1077.78     <- BC
      381.05   150.00    538.89   1077.78     <- CA

 >> M = IE.fasores(220, 15)      % gira todo 15 grados

 Los angulos salen en [0, 360). BN = 240 es lo mismo que -120.
 Coherencia garantizada: E_AB = E_AN - E_BN exacto, y la linea adelanta

 Para pasar la tabla a complejos:

-------------------------------------------------------------------------------
 res = IE.despejar(eqs, S, d)
-------------------------------------------------------------------------------
   eqs : sistema simbolico (de IE.ecB, IE.ecTrafo, IE.ecPerdidas, ...)
   S   : diccionario de simbolos del MISMO sistema
   d   : struct con SOLO lo que sabes, en cualquier orden
   res : struct con TODAS las variables que quedaron determinadas.
         Para numero: double(res.Fi) o vpa(res.Fi, 6).

 NO SE PIDE UNA INCOGNITA, A PROPOSITO.
   La sustitucion hacia adelante determina TODO lo que los datos permitan,
   en la misma pasada. Pedir una variable no ahorraba trabajo: solo elegia
   cual de las ya calculadas devolver y escondia el resto. Elegis vos, del
   struct.
   SI UN CAMPO NO ESTA EN res, ES QUE LOS DATOS NO ALCANZARON para
   determinarlo. Ese es el diagnostico: mira que falta.

 POR QUE NO ES UN solve() PELADO
   solve(eqs, x) exige que TODAS las ecuaciones se satisfagan moviendo
   unicamente x. Como el sistema tiene incognitas intermedias (H, B, Rn...),
   cualquier ecuacion que no contenga x lo vuelve insatisfacible y solve
   devuelve VACIO aunque los datos alcancen de sobra. Verificado en R2026a.
   Aca se hace SUSTITUCION HACIA ADELANTE, que es exactamente el metodo a
   mano: se busca una ecuacion con una sola incognita, se despeja, se
   propaga el valor a todas, y se repite hasta que no queda nada.

 >> [eqs, S] = IE.ecSeg();
 >> r = IE.despejar(eqs, S, struct('len',.3,'A',1e-3,'mu',5e3,'g',0));
 >> double(r.Rn)
    ans = 47746

 S ES INDISPENSABLE: cada llamada a una "ec" crea simbolos NUEVOS, asi que
 una N que declares vos por fuera NO es la misma N que esta adentro de eqs.
 Usando S siempre pegan.

 ERRORES Y AVISOS
   IE:campoDesconocido     le pasaste un campo que no es del modelo
   IE:datosContradictorios los datos violan una ecuacion
   IE:variasSoluciones     la ecuacion era cuadratica; se toma la primera

 Los pasos intermedios vienen gratis en el mismo struct:

 Igual pero sobre UN TRAMO con entrehierro. Variables disponibles:

 OJO con g: si no lo pasas queda como incognita y Rn no se puede despejar.

-------------------------------------------------------------------------------
 EL STRUCT DE TRAMO  (lo comen reluctSeg, fluxO y fluxE)
-------------------------------------------------------------------------------
   len   longitud media del tramo                [m]    OBLIGATORIO
   mu    permeabilidad RELATIVA                  [-]    OBLIGATORIO
   A     seccion                                 [m^2]  (o dar a y b)
   a, b  lados de la seccion rectangular         [m]    -> A = a*b
   g     entrehierro DENTRO del tramo            [m]    opcional, 0
   dA    crecimiento proporcional del area       [-]    opcional
   n     veces que el tramo aparece en serie     [-]    opcional, 1

 FRINGING: el flujo se abre al cruzar el gap, asi que la seccion efectiva
 del entrehierro es mayor:  A_gap = A*(1 + dA).
   - Si das a y b y NO das dA, se calcula solo:  A_gap = (a+g)*(b+g)
   - Si das dA explicito, MANDA EL TUYO (el dato de la catedra gana).
   - Si no das ninguno, dA = 0 (sin fringing).

 El campo n es para tramos repetidos: un U+I tiene dos contactos identicos,
 entonces gap.n = 2 y no hace falta escribir el tramo dos veces.

 >> s  = struct('len',0.3, 'A',1e-3, 'mu',5000);                    % simple
 >> sg = struct('len',0.3, 'A',1e-3, 'mu',5000, 'g',1e-3, 'dA',0.1);% con gap
 >> sab= struct('len',0.3, 'mu',5000, 'a',0.02, 'b',0.05, 'g',1e-3);% fringing solo

-------------------------------------------------------------------------------
 [R, det] = IE.reluctSeg(s)
-------------------------------------------------------------------------------
 Reluctancia de UN tramo. La pieza para armar a mano cualquier nucleo.

   R   : reluctancia total del tramo, ya multiplicada por n   [A-v/Wb]
   det : struct con el detalle
           det.Rn    parte del hierro
           det.Rg    parte del entrehierro
           det.A     seccion del hierro
           det.Agap  seccion efectiva del gap = A*(1+dA)
           det.g  det.dA  det.n  det.mu

 >> [R, det] = IE.reluctSeg(sg);
 >> det.Rn / R * 100      % que porcentaje aporta el hierro

 PARA ARMAR NUCLEOS RAROS:
   serie    -> sumar:      Rt = IE.reluctSeg(s1) + IE.reluctSeg(s2) + ...
   paralelo -> IE.parZ:    Rp = IE.parZ([IE.reluctSeg(s1), IE.reluctSeg(s2)])
   despues:  Fi = N*I/Rt

 Errores que tira a proposito:
   IE:gapMayorQueTramo    g > len
   IE:muRelativa          mu < 1 (pusiste la absoluta)
   IE:areaInconsistente   diste a, b Y A y no coinciden
   IE:faltaArea           no diste ni A ni (a,b)

-------------------------------------------------------------------------------
 r = IE.fluxO(seg, N, I)
 r = IE.fluxO(seg, N, I, Bsat)
-------------------------------------------------------------------------------
 NUCLEO TIPO O: camino magnetico CERRADO en SERIE. Cuadrado, rectangular,
 toroide, U+I, E-I armado. Todos son un solo lazo: el flujo no se divide.

     +-------+      Rt = R1 + R2 + R3 + R4 (+ Rgap)
     |       |      Fi = N*I / Rt
     |       |
     +-------+

   seg  : los tramos. Dos formas:
            cell array  {s1, s2, s3}     <- USA ESTA
            struct array [s1 s2 s3]
          El cell array existe porque MATLAB no deja concatenar structs con
          campos distintos (uno con 'g' y otro sin). Con llaves no importa.
   N, I : vueltas y corriente
   Bsat : umbral de aviso de saturacion [T]. Opcional, 1.5 por defecto.

   r.fmm    N*I                                        [A-vuelta]
   r.Rt     reluctancia total                          [A-v/Wb]
   r.Fi     flujo (uno solo, es serie)                 [Wb]
   r.L      inductancia N^2/Rt                         [H]
   r.R      reluctancia por tramo                      [A-v/Wb]
   r.frac   fraccion de Rt que aporta cada tramo       [-]
   r.caida  caida de fmm por tramo, Fi*R               [A-vuelta]
   r.B      densidad en el HIERRO de cada tramo        [T]
   r.Bg     densidad en el ENTREHIERRO (NaN si no hay) [T]
   r.F      fuerza de atraccion por entrehierro        [N]
   r.Ftot   fuerza total                               [N]
   r.sat    logico: tramos con B por encima de Bsat

 FUERZA:  F = Bg^2 * A_gap / (2*mu0)  por cada superficie de contacto.
          Si el tramo tiene n = 2, la fuerza ya viene multiplicada por 2.

 >> s = struct('len',0.3, 'A',1e-3, 'mu',5000);
 >> r = IE.fluxO({s, s, s, s}, 100, 1);
 >> r.Fi        % 5.2360e-04 Wb
 >> r.L         % 0.052360 H
 >> r.B(1)      % 0.52360 T   comodo, no satura

 El warning de saturacion NO es un error: el numero sale igual. Te esta
 diciendo que ese numero es OPTIMISTA, porque el modelo es lineal y en la
 realidad mu se desploma al saturar: el flujo real es MENOR.

 CONTROL QUE SIEMPRE DEBE DAR:   sum(r.caida) == r.fmm    (ley de Ampere)
 >> abs(sum(r.caida) - r.fmm) < 1e-9      % true

-------------------------------------------------------------------------------
 [Fi, Rt, r] = IE.fluxE(R, b, N, I)
 [Fi, Rt, r] = IE.fluxE(R, b, N, I, sentido)
-------------------------------------------------------------------------------
 NUCLEO TIPO E: bobina en UNA pierna, el flujo vuelve repartido por las
 otras dos, que quedan en PARALELO.

     +-+-+        Rt = R(b) + ( R(otra1) // R(otra2) )
     | | |        Fi(b)     = N*I / Rt
     +-+-+        Fi(otras) = divisor sobre R, con signo opuesto

   R : las 3 piernas. Tres formas:
         vector numerico   [R1 R2 R3]     reluctancias ya calculadas
         cell array        {s1, s2, s3}   tramos
         struct array      [s1 s2 s3]     tramos
   b : indice 1, 2 o 3 de la pierna BOBINADA
   N, I    : vueltas y corriente
   sentido : +1 / -1, orientacion de la fmm. Opcional, +1.

   Fi : 3x1. Todos los flujos medidos ENTRANDO al yugo superior, o sea
        sum(Fi) = 0. Las piernas de retorno salen con signo OPUESTO a Fi(b).
   Rt : reluctancia vista por la bobina
   r  : siempre trae r.R, r.frac, r.L, r.Fi.
        Si pasaste TRAMOS (no numeros pelados) trae ademas
        r.B, r.Bg, r.F, r.Ftot, r.sat.

 >> [Fi, Rt] = IE.fluxE([1e5 2e5 2e5], 1, 100, 1);
 >> Fi
    5.0000e-04     <- pierna 1, la bobinada
   -2.5000e-04     <- vuelve por la 2
   -2.5000e-04     <- vuelve por la 3
 >> sum(Fi)        % 0, ley de nodos magnetica

 CONTROL QUE SIEMPRE DEBE DAR:   sum(Fi) == 0

 QUE DESPRECIA (leer antes de confiar en el numero):
   1) Los YUGOS (las barras que unen las 3 piernas) NO estan modelados.
      Se asume su reluctancia despreciable. Vale si son cortos y gruesos;
      deja de valer si hay entrehierro en el yugo.
   2) Flujo de dispersion entre piernas: cero.
   3) Es lineal, sin curva B-H.
   Para el E simetrico con bobina en la pierna central el error es chico.
   Si las piernas son muy asimetricas o hay gap en el yugo, arma las mallas
   a mano con reluctSeg y parZ.


===============================================================================
 4. TRANSFORMADOR MONOFASICO
 Tres modelos, de menos a mas realista:
   ecTrafo     -> IDEAL, solo relaciones de vueltas
   ecPerdidas  -> con perdidas y rendimiento
   ecPerAprox  -> circuito equivalente APROXIMADO, con Req, Xeq, Rc, Xm
===============================================================================

-------------------------------------------------------------------------------
 r   = IE.trafo(d)             <- numerico, el que vas a usar
 res = IE.datosTrafo(d)        <- lo mismo pero simbolico
 [eqs, S] = IE.ecTrafo()
-------------------------------------------------------------------------------
 TRANSFORMADOR IDEAL: sin dispersion, sin resistencia de bobinado, sin
 perdidas en el hierro y con corriente de magnetizacion nula (mu -> inf).

   Variables: a  b  Np  Ns  Vp  Vs  Ip  Is  Zp  Zs  dFi

   Vp = a*Vs      Ip = Is/a      Zp = a^2*Zs
 La tension y la corriente van con a; la impedancia con a AL CUADRADO.

 >> r = IE.trafo(struct('a',10, 'Vp',2200, 'Zs',5));
 >> r.Vs, r.Is, r.Ip, r.Zp

 trafo devuelve numeros (ya pasados por double) y ademas te copia los datos
 de entrada al struct de salida. Acepta complejos.

-------------------------------------------------------------------------------
 r   = IE.perdidas(d)          <- numerico, entra por los DOS ENSAYOS
 res = IE.datosPerdidas(d)     <- version simbolica, despeja en cualquier sentido
 [eqs, S] = IE.ecPerdidas()
-------------------------------------------------------------------------------
 QUE REPRESENTA CADA PERDIDA

   COBRE   Pcu = I^2*Req        efecto Joule en los dos devanados
   NUCLEO  Pfe = Ph + Pe        de origen magnetico, adentro del hierro
     Ph = kh*f*Bmax^n           HISTERESIS: la energia de dar vuelta los
                                dominios en cada ciclo. Es el area del lazo
                                B-H. n = 1.6 a 2 (Steinmetz).
     Pe = ke*f^2*Bmax^2*esp^2   CORRIENTES PARASITAS (Foucault): el flujo
                                variable induce corrientes DENTRO del hierro,
                                que es conductor. Van con el CUADRADO del
                                espesor de la chapa: por eso se LAMINA.
   ADICIONALES (dispersion)     no se calculan aparte: el ensayo de
                                cortocircuito ya las mide con el cobre.
   MECANICAS                    no hay. El trafo no tiene partes moviles.

 COMO SE CATALOGAN

   1) POR SU DEPENDENCIA DE LA CARGA   <- la que importa
        VARIABLES  Pcu, van con el CUADRADO de la corriente:
                   Pcu(x) = x^2 * PcuNom.  En vacio valen CERO.
        FIJAS      Pfe, dependen de la TENSION y la FRECUENCIA, no de la
                   carga. Estan desde que energizas, aun con el secundario
                   abierto. Tambien se las llama "de vacio".

   2) POR DONDE SE PRODUCEN
        cobre (devanados) / hierro (nucleo) / adicionales (dispersion)

   3) POR EL ENSAYO QUE LAS MIDE
        VACIO (circuito abierto, por el lado de BAJA): la corriente es la de
          excitacion, 2-5% de la nominal, asi que el I^2*Req es despreciable.
          El vatimetro lee Pfe.
        CORTOCIRCUITO (por el lado de ALTA): tension chica, 3-10% de la
          nominal, hasta la corriente nominal. El flujo va con la tension,
          asi que Pfe es despreciable. El vatimetro lee Pcu.
        Cada ensayo anula la otra familia. Ese es todo el truco.

 RENDIMIENTO
   eta = Pout / (Pout + Pfe + Pcu)
   Es MAXIMO cuando las variables igualan a las fijas, Pcu = Pfe. Como
   Pcu = x^2*PcuNom, eso pasa en   xopt = sqrt(Pfe/PcuNom).
   Un trafo de distribucion, que pasa muchas horas con poca carga, se disena
   a proposito con xopt < 1.

 ENTRADAS de IE.perdidas (todas opcionales, se usa lo que haya)
   Ensayo de vacio        Poc  Voc  Ioc
   Ensayo de cortocircuito Psc  Vsc  Isc
   Directos               Pfe  Pcu  PcuNom  Req  Xeq  Padd
   Punto de carga         x (default 1)  I  Inom  S  Snom  V  FP  tipoFP
   Separacion del nucleo  kh  ke  f  Bmax  esp  nst (default 1.6)

 SALIDAS
   r.Pfe r.Ph r.Pe        nucleo: total, histeresis, Foucault    [W]
   r.Pcu r.PcuNom         cobre: en el punto y a plena carga     [W]
   r.Padd r.Pperd         adicionales y TOTAL                    [W]
   r.Pout r.Pin           potencia util y de entrada             [W]
   r.eta r.etapct         rendimiento en tanto por uno y en %
   r.x r.xopt r.etamax    carga analizada, carga de rendimiento maximo y su eta
   r.Req r.Xeq r.Zeq      impedancia serie                       [ohm]
   r.Rc r.Xm r.Im r.Ife   rama de excitacion                [ohm, A]
   r.Vp_a r.RV            Vp/a del diagrama fasorial y la regulacion en %
   r.tabla                TABLA con cada perdida: W, % del total, si es fija
                          o variable, de que depende y que ensayo la mide

 >> d = struct('Poc',80, 'Voc',240, 'Ioc',1.2, ...
               'Psc',300, 'Vsc',120, 'Isc',6.25, ...
               'Snom',15e3, 'V',2400, 'FP',0.85);
 >> r = IE.perdidas(d);
 >> r.Req        % 7.68 ohm      r.Xeq   % 17.60 ohm
 >> r.etapct     % 97.11 %       r.RV    % 4.15 %
 >> r.xopt       % 0.5164        r.etamax% 97.63 %

      COBRE  (Pcu)    300   78.95%   variable   I^2*Req -> x^2         cortocircuito

 OJO CON EL LADO AL QUE ESTA REFERIDO CADA VALOR
   Las POTENCIAS no tienen lado: 80 W son 80 W se midan donde se midan.
   Las IMPEDANCIAS si: como el ensayo de vacio se hace por BAJA y el de
   cortocircuito por ALTA, r.Rc y r.Xm quedan referidas a BAJA y r.Req,
   r.Xeq a ALTA. Para pasarlas al otro lado, por a^2.
   Los V, I, Inom, S que le pases tienen que ser del MISMO lado que Req.

-------------------------------------------------------------------------------
 [eqs, S] = IE.ecPerAprox()
-------------------------------------------------------------------------------
 CIRCUITO EQUIVALENTE APROXIMADO. La aproximacion consiste en correr la rama
 de excitacion a los bornes de entrada: asi toda la caida Req + jXeq queda
 del lado de la carga y las dos ramas quedan en paralelo directo.

            Ip      Req     jXeq        Is
      o----->----[====]---[====]----->----o
                 |     |                  |
    Vp/a        Rc   jXm                  Vs   (carga)
                 |     |                  |
      o----------+-----+------------------o

 Todo REFERIDO AL SECUNDARIO y en FASORES (complejos, no modulos):

   Vpa = Vp/a          Vpa = Vs + Zeq*Is        Zeq = Req + j*Xeq
   Ic  = Vpa/Rc        Im  = Vpa/(j*Xm)         Iexc = Ic + Im
   a*Ip = Is + Iexc

 >> [eqs, S] = IE.ecPerAprox();
 >> r = IE.despejar(eqs, S, struct('Vs',240, 'Is',IE.pol2rec(50,-30), ...
                                   'Req',0.05, 'Xeq',0.12, 'a',10));
 >> abs(double(r.Vpa))      % 245.20 V,  a 0.92 grados
 >> abs(double(r.Vp))       % 2451.97 V

 La regulacion sale de aca: RV = (|Vpa| - |Vs|)/|Vs| * 100, y tambien la
 calcula IE.perdidas como r.RV.


===============================================================================
 5. TRANSFORMADORES TRIFASICOS  (clase TT, archivo TT.m)
===============================================================================

 Se usa igual que IE: metodos estaticos, se les pasa un struct.

   TT.YY(d)    Estrella - Estrella
   TT.DD(d)    Delta - Delta
   TT.YD(d)    Estrella - Delta
   TT.DY(d)    Delta - Estrella
   TT.mono(d)  Monofasico: mismos campos, sin sqrt(3)

 Cada una arma el sistema de su conexion y lo pasa por IE.despejar, asi que
 anda en cualquier direccion. Devuelve los datos de entrada MAS todo lo que
 se pudo despejar, ya en double.

 VARIABLES (todas opcionales, se usa lo que haya)
   V_LP  V_phiP  V_LS  V_phiS         tensiones de linea y de fase   [V]
   I_LP  I_phiP  I_LS  I_phiS         corrientes de linea y de fase  [A]
   ang_VLP ang_VphiP ang_VLS ang_VphiS   angulos de las tensiones  [grados]
   ang_ILP ang_IphiP ang_ILS ang_IphiS   angulos de las corrientes [grados]
   a        relacion de transformacion POR FASE, a = V_phiP/V_phiS   [-]
   N_P N_S  vueltas por fase de cada devanado                        [-]
   S        potencia aparente TRIFASICA, sqrt(3)*V_L*I_L            [VA]
   theta    angulo del factor de potencia de la carga, + atrasado [grados]
   desf     desfase de la conexion, ang_VLP - ang_VLS             [grados]

 ANGULOS: si no pasas ninguno, se toma ang_VphiP = 0 como referencia.
   Sin theta NO salen los angulos de las corrientes.

 DE DONDE SALE EL DESFASE (no esta puesto a mano, cae solo)
   Y : V_L = sqrt(3)*V_phi, la linea ADELANTA 30 a la fase
       I_L = I_phi, mismo angulo
   D : V_L = V_phi, mismo angulo
       I_L = sqrt(3)*I_phi, la linea ATRASA 30 a la fase
   Las bobinas del mismo nucleo van en fase (punto con punto), o sea
   ang_VphiS = ang_VphiP. Combinando eso con las dos reglas de arriba:

     conexion   V_LP/V_LS      desf     que le pasa al secundario
     --------   -----------    -----    -------------------------
     Y-Y        a               0       en fase
     D-D        a               0       en fase
     Y-D        sqrt(3)*a     +30       ATRASA 30 grados
     D-Y        a/sqrt(3)     -30       ADELANTA 30 grados

   Si tu banco esta marcado al reves (permutando dos fases) el signo se
   invierte: es la diferencia entre Dy11 y Dy1.
   Dos bancos de conexion distinta NO se pueden poner en paralelo: por eso
   este desfase importa.

 >> r = TT.DY(struct('V_LP',13800, 'a',10))
    r.V_phiP = 13800      r.ang_VphiP = 0
    r.V_LS   = 2390.23    r.ang_VLS   = 30
    r.V_phiS = 1380       r.desf      = -30

 >> r = TT.DY(struct('V_LP',13800, 'a',10, 'S',500e3, 'theta',36.87));
 >> r.I_LP, r.ang_ILP      % 20.92 A a -66.87 grados
                           % (-36.87 del FP, -30 mas por la delta)
 >> r.I_LS, r.ang_ILS      % 120.77 A a -36.87 grados

 CONTROL QUE SIEMPRE DEBE DAR:  sqrt(3)*V_LP*I_LP == sqrt(3)*V_LS*I_LS == S

 >> m = TT.mono(struct('V_LP',2400, 'a',10, 'S',15e3, 'theta',31.79));
 >> m.V_LS, m.I_LP, m.I_LS      % 240 V, 6.25 A, 62.5 A, desf = 0

 Los archivos TT_YY.m, TT_DD.m, TT_YD.m y TT_DY.m son los apuntes viejos con
 los diagramas; los mismos diagramas estan adentro de TT.m.

===============================================================================
 7. LIMITES CONOCIDOS
===============================================================================

 - TODO EL MODELO MAGNETICO ES LINEAL. mu es constante, no hay curva B-H.
   Si un tramo pasa de ~1.5 T, fluxO avisa. Ese aviso significa: el numero
   que te dio es OPTIMISTA. En la realidad mu se desploma al saturar y el
   flujo real es MENOR. Con saturacion hay que ir a la curva B-H a mano.

 - fluxE ignora los yugos y la dispersion entre piernas (ver su seccion).

 - f2l y l2f son solo modulos, no aplican el desfase de 30 grados.

 - fasores asume equilibrio perfecto y secuencia positiva.

 - potencias no distingue potencia por fase de potencia trifasica: si le
   pasas magnitudes de fase te da potencia de fase. Multiplica por 3 vos.

 - datosB usa un modelo de UN camino uniforme. Para nucleos con varios
   tramos distintos usa fluxO o arma con reluctSeg.

 - ecTrafo es el trafo IDEAL: no tiene perdidas ni dispersion. Para eso
   estan ecPerdidas y ecPerAprox.

 - perdidas no separa las perdidas adicionales: quedan adentro de Pcu,
   que es lo que mide el ensayo de cortocircuito.

 - Con Pfe hay que dar kh/ke (o Ph, o Pe) para separar histeresis de
   Foucault. Con un solo ensayo de vacio no se pueden separar: hay que
   repetirlo a dos frecuencias distintas.

 - TT asume las tres fases EQUILIBRADAS y el transformador IDEAL: no le
   metas perdidas, para eso esta IE.perdidas por fase.

 - TT no modela el terciario en delta ni la conexion en zig-zag.
